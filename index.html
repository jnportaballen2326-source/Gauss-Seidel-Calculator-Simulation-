Gauss–Seidel
Iteration

Overview

The Gauss–Seidel method is an iterative technique for solving a square linear system $A\mathbf{x} = \mathbf{b}$. Starting from an initial guess, it repeatedly updates each unknown using the most recently computed values of all other unknowns — making it faster than Jacobi iteration.

Update Formula

For each variable $x_i$ at iteration $k+1$:

$$\boxed{x_i^{(k+1)} = \frac{b_i \;-\; \displaystyle\sum_{j=1}^{i-1} a_{ij}\,x_j^{(k+1)} \;-\; \displaystyle\sum_{j=i+1}^{n} a_{ij}\,x_j^{(k)}}{a_{ii}}}$$

Terms with $j < i$ use the already-updated values from the current sweep. Terms with $j > i$ use the previous iteration's values.

Absolute Relative Approximate Error

After each iteration, the error for each variable is:

$$\varepsilon_i = \left|\frac{x_i^{new} - x_i^{old}}{x_i^{new}}\right| \times 100\%$$

Iteration continues until all $\varepsilon_i$ fall below a specified tolerance, or the maximum number of iterations is reached.

Step-by-Step Procedure

Step 1: Check diagonal dominance
         |a_ii| > Σ|a_ij| for j≠i  (guarantees convergence)

Step 2: Rearrange each equation to isolate x_i
         x_i = (b_i - Σ a_ij·x_j) / a_ii

Step 3: Choose initial guess x⁰

Step 4: For each iteration k = 1, 2, 3, …
           For each i = 1 to n:
             substitute current x values into formula
             compute x_i new
             compute εᵢ = |x_new - x_old| / |x_new| × 100%

Step 5: If all εᵢ < tolerance → STOP (converged)
         Else → repeat Step 4

Convergence Condition

✦

Diagonal Dominance

Convergence guaranteed when each diagonal entry exceeds the sum of all other entries in the same row:

$$|a_{ii}| > \sum_{j \neq i} |a_{ij}|$$
✦

Symmetric Positive Definite

If $A = A^T$ and all eigenvalues are positive, Gauss–Seidel is also guaranteed to converge.

✦

Rearranging Equations

If the system is not diagonally dominant as written, try reordering the rows so that the largest coefficients fall on the diagonal.

Example 1

3 × 3 System

Solve the system with initial guess $x_1=1,\; x_2=0,\; x_3=1$:

$$\begin{cases}12x_1 + 3x_2 - 5x_3 = 1\\ x_1 + 5x_2 + 3x_3 = 28\\ 3x_1 + 7x_2 + 13x_3 = 76\end{cases}$$

Step 1 — Diagonal Dominance

$$\begin{bmatrix}12 & 3 & -5\\1 & 5 & 3\\3 & 7 & 13\end{bmatrix}$$

Row 1: $|12| = 12 > |3|+|-5| = 8$ ✓
Row 2: $|5| = 5 > |1|+|3| = 4$ ✓
Row 3: $|13| = 13 > |3|+|7| = 10$ ✓

Step 2 — Rearrange

$$x_1 = \frac{1 - 3x_2 + 5x_3}{12}, \quad x_2 = \frac{28 - x_1 - 3x_3}{5}, \quad x_3 = \frac{76 - 3x_1 - 7x_2}{13}$$

Iteration 1 — using $x_1=1,\;x_2=0,\;x_3=1$

$$x_1 = \frac{1 - 3(0) + 5(1)}{12} = \frac{1 - 0 + 5}{12} = \frac{6}{12} = 0.5$$ $$\varepsilon_1 = \left|\frac{0.5 - 1}{0.5}\right| \times 100 = 100\%$$ $$x_2 = \frac{28 - 0.5 - 3(1)}{5} = \frac{28 - 0.5 - 3}{5} = \frac{24.5}{5} = 4.9$$ $$\varepsilon_2 = \left|\frac{4.9 - 0}{4.9}\right| \times 100 = 100\%$$ $$x_3 = \frac{76 - 3(0.5) - 7(4.9)}{13} = \frac{76 - 1.5 - 34.3}{13} = \frac{40.2}{13} \approx 3.092$$ $$\varepsilon_3 = \left|\frac{3.092 - 1}{3.092}\right| \times 100 \approx 67.66\%$$

Iteration 2 — using updated values

$$x_1 = \frac{1 - 3(4.9) + 5(3.092)}{12} = \frac{1 - 14.7 + 15.46}{12} = \frac{1.76}{12} \approx 0.1468$$ $$\varepsilon_1 = \left|\frac{0.1468 - 0.5}{0.1468}\right| \times 100 \approx 240.6\%$$ $$x_2 = \frac{28 - 0.1468 - 3(3.092)}{5} = \frac{28 - 0.1468 - 9.276}{5} = \frac{18.577}{5} \approx 3.715$$ $$\varepsilon_2 = \left|\frac{3.715 - 4.9}{3.715}\right| \times 100 \approx 31.9\%$$ $$x_3 = \frac{76 - 3(0.1468) - 7(3.715)}{13} = \frac{76 - 0.4404 - 26.005}{13} = \frac{49.555}{13} \approx 3.812$$ $$\varepsilon_3 = \left|\frac{3.812 - 3.092}{3.812}\right| \times 100 \approx 18.9\%$$

Example 2

4 × 4 Heat Conduction System

Solve with initial guess $\mathbf{T}^{(0)} = (0,0,0,0)$:

$$\begin{bmatrix}4&-1&0&-1\\-1&4&-1&0\\0&-1&4&-1\\-1&0&-1&4\end{bmatrix}\begin{bmatrix}T_1\\T_2\\T_3\\T_4\end{bmatrix}=\begin{bmatrix}100\\200\\200\\100\end{bmatrix}$$

Step 1 — Diagonal Dominance

Every row: $|4| = 4 > |-1|+|-1| = 2$ ✓ → Convergence guaranteed.

Step 2 — Rearrange

$$T_1 = \frac{100 + T_2 + T_4}{4}, \quad T_2 = \frac{200 + T_1 + T_3}{4}$$ $$T_3 = \frac{200 + T_2 + T_4}{4}, \quad T_4 = \frac{100 + T_1 + T_3}{4}$$

Iteration 1

$$T_1 = \frac{100 + 0 + 0}{4} = 25.0 \qquad \varepsilon_1 = 100\%$$ $$T_2 = \frac{200 + 25 + 0}{4} = 56.25 \qquad \varepsilon_2 = 100\%$$ $$T_3 = \frac{200 + 56.25 + 0}{4} = 64.0625 \qquad \varepsilon_3 = 100\%$$ $$T_4 = \frac{100 + 25 + 64.0625}{4} = 47.2656 \qquad \varepsilon_4 = 100\%$$
